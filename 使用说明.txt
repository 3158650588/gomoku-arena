五子棋对决 · v6.0 擂台版

手机和电脑使用同一套网页代码。
首次开局默认你执白，AI 执黑先下。标题页可选择「执黑」或「执白」，并自动记住选择。
执白时，悔棋撤回自己的上一手和 AI 的应手，开局第一枚黑子留在棋盘上。

模式和复盘

「开局」可以选六档棋力、均衡 / 偏进攻 / 偏防守、三套皮肤，或开始本地双人。
想挑战最高棋力，在「设置」选择「擂台」，开局选大师。深算和擂台会重新计算常见开局，并在遇到强杀时比较应手。
Windows 电脑使用 start-game.cmd 启动，选均衡棋风和自由规则后可调用本机多线程 Rapfi。棋盘会显示当前使用的引擎。手机也可开启擂台。
默认自由五子棋。开启「黑棋禁双三」后，黑棋一手形成两条活三要换点，成五优先，白棋照常下。
可以开启「快棋 5+3」，每方 5 分钟，每手加 3 秒。
对局自动保存。回来后从「继续上次对局」恢复棋盘和轮次。
「训练」有六道残局和三个换色挑战开局。换色挑战同一开局先黑后白，按胜 1、平 0.5、负 0 合计。
「训练」还可挑战每日残局、带优势开局的让子挑战，或选择最近一盘败局练防守和换边取胜。
「训练」也可以自定义摆棋，选择黑先或白先后继续和 AI 下。已经形成五连的局面需要先调整。
终局点「复盘本局」，用上一步、下一步或进度条回看。点「从这手重下」可开启一盘分支练习。
回放中可「对照禁双三」或「对照自由规则」。在设置开启残局精算后，剩 10 个空位以内可以尝试计算胜负和手数。
「棋谱」保存本浏览器最近 24 局。导出的 JSON 可以发给朋友，用本游戏的「导入棋谱」打开。
「战绩」按难度和执子颜色记录普通人机的胜负平。旧版的总成绩会继续显示。

开发与手机联调

1. 解压源码，在目录里运行 npm ci 。
2. 运行 npm run dev -- --host 0.0.0.0 。
3. 手机与电脑连接同一 Wi-Fi，用手机浏览器打开 Vite 输出的 Network 地址。
   也可以运行 npm run build，把整个 dist/ 目录部署到静态网站，然后在手机浏览器打开网址。

手机操作

在大厅或暂停菜单打开「设置」，选「轻点直接下」或「先预览、再确认」。可以先在设置的小棋盘试点。
使用预览时，再点同一处或按「确认落子」才落子。从预览棋上拖动可以微调。其他位置单指拖动旋转视角，双指捏合或张开缩放。
棋盘缩放或旋转后，点「复位视角」即可恢复默认位置。横竖屏切换会保留正在进行的对局。
点「俯视」可以在正上方看棋盘，再点「3D 视角」可切回。轮到自己时可以逐级请求提示。
选「暂停」可在对局中换皮肤。难度、皮肤和战绩保存在当前浏览器。

电脑试玩

试玩包解压后双击 start-game.cmd 即可打开网页。本机需安装 Node.js。
手机试玩时，电脑双击 start-mobile.cmd，手机连同一个 Wi-Fi 后访问窗口中的 Phone browser address。
使用源码包时，先在源码目录运行 npm ci 和 npm run build，再双击 start-game.cmd 。
浏览器若未自动打开，访问启动窗口显示的地址。关闭启动窗口即可结束本地服务。

自由模式首次进入高手或大师档时，浏览器要加载约 40 MB 的棋力模型。禁双三模式使用后台本地 AI。
Rapfi 的许可、源码和重建信息随包附上，见 third-party/rapfi/README.md。
